# OPP Wars: Corruption — Web Edition 0.2.0

Standalone GitHub repository: https://github.com/SeraphinaDX/oppwars-corruption-web

This archive matches the standalone repository layout. Copy all files **inside** the `web` directory to the root of your fork, overwriting the older files; then run:

```sh
go test ./...
go run .
```

Open http://127.0.0.1:8080 in your browser. Existing save files continue working. Default binding is localhost; do not deploy publicly without security hardening. See README.md for balance rules.
